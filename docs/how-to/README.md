# How-to guides

How-to guides are for when Falco is already part of your plan and you need to get one specific thing done: add it to a build, load an Anvil world, compute light, migrate an older world, or reproduce a published measurement. Each page assumes you know the goal and gives the steps to reach it, with little about why they are the steps. If you are starting from nothing, begin with the tutorial, and for the reasons behind a step, see [Explanation](../explanation/README.md).
