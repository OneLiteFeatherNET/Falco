# Project record

The project record holds the time-bound part of the documentation: the status of the Anvil chunk loader and the light engine, and the investigations that were run before decisions were made. Its pages describe the project as it was when they were written, so they are not a description of current behaviour; that is what Reference and Explanation are for. Read the status page for what is open, built, measured and rejected, and the research notes for the reasoning behind a past choice.
